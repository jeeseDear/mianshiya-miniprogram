下面代码的输出是什么？
javascript
let a = 3
let b = new Number(3)
console.log(a == b)
console.log(a === b)
A
true、false
B
false、false
✓
C
true、true
D
false、true
回答正确
答案 B
解析
new Number(3) 是一个对象，不是数字。a == b 时，b 会被转换成原始值 3，但这里比较的是对象与数字，结果仍为 false；a === b 要求类型相同，同样为 false。
